# Archive - Previous Versions

This folder contains earlier development versions and experimental implementations. These files are kept for reference but are **not recommended** for new installations.

## Files in This Archive

### Early Inline Implementations
- `ghost-site-header-INLINE.html` - First dark version with ES module fix
- `ghost-site-header-INLINE-LIGHT.html` - Light/inverse color version
- `ghost-site-header-INLINE-v4.html` - Version locked to Littlefoot 4.0.0

### Experimental Versions
- `ghost-site-header-AGGRESSIVE-STYLING.html` - Triple class selectors for maximum CSS specificity
- `ghost-site-header-INLINE-DIAGNOSTIC.html` - Diagnostic version with console logging
- `ghost-site-header-MINIMAL.html` - Minimal lightweight version

### Standalone Files
- `littlefoot-custom.css` - Standalone CSS file (requires external hosting)
- `littlefoot-init.js` - Standalone JavaScript file (requires external hosting)
- `ghost-header-injection.html` - Early code snippets

### Original Documentation (Outdated)
- `IMPLEMENTATION-GUIDE.md` - Old setup instructions
- `SIMPLE_INSTALL_GUIDE.md` - Old quick start guide
- `QUICK-REFERENCE.md` - Old customization reference
- `PASTE-THIS-IN-GHOST.html` - Early unified attempt

## Why These Are Archived

These versions had various issues:
- **Tiny buttons** - CSS specificity problems with Ghost themes
- **ES module errors** - Initial attempts at fixing the `littlefoot is not a function` error
- **Multiple files** - Confusion about which files to use
- **Incomplete features** - Missing toggle functionality

## Current Recommended Versions

Use these files in the **root directory** instead:

1. **UNIFIED Toggle Version - Install Once Use Everywhere.html** ⭐ RECOMMENDED
2. **SIMPLIFIED Styling littlefoot_Site Header Code_2025-12-27.html**

## When to Use Archive Files

You might reference these files if:
- Debugging CSS specificity issues (see `ghost-site-header-AGGRESSIVE-STYLING.html`)
- Understanding the development history
- Looking for alternative implementation approaches
- Your Ghost theme requires extra-aggressive CSS overrides

Otherwise, use the current versions in the root directory.
