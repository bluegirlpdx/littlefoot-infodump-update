🔍 How Littlefoot Popovers Work - Technical Explanation

Your Question:

"Will the footnotes actually show popover bubbles with content, or just link to the bottom of the page?"

✅ Answer: YES, they will show FULL popover bubbles!

The popover functionality comes from the official Littlefoot.js library, not from custom code. Our code only makes them look pretty with your brand colors.

📚 What Littlefoot.js Does (The Popover Engine)

When you load Littlefoot from the CDN, you get the COMPLETE library that handles:

  1. Finding footnotes: Scans your HTML for footnote links like <a href="#fn:1">1</a>
  2. Creating buttons: Replaces links with clickable buttons
  3. Building popovers: Creates the bubble element with the footnote content
  4. Positioning: Calculates where to place the bubble (above/below the button)
  5. Show/hide logic: Handles click events to toggle the popover
  6. Animations: Fades the popover in and out smoothly
  7. Accessibility: Adds ARIA labels, keyboard navigation, etc.
Important: This is ALL built into Littlefoot.js. You don't write any of this code - it's done automatically!

🎨 What Our Custom Code Does

Our code ONLY adds styling on top of Littlefoot's existing functionality:

  1. Button colors: Changes from default blue to your brand colors (#610317, #fbe8e8)
  2. Button size: Makes buttons larger (0.9rem instead of default)
  3. Font weight: Makes text bolder (900-weight instead of 400)
  4. Hover effects: Adds color change and rise animation
  5. Popover styling: Styles the bubble's border, shadow, padding, etc.
Key Point: Our code does NOT create or control the popover functionality. Littlefoot.js does that. We just make it look better!

🔄 Step-by-Step: What Happens on Your Ghost Site

Step 1: You write a footnote in Ghost using Markdown:

This is a sentence with a footnote.[^1] [^1]: This is the content that will appear in the popover bubble.

Step 2: Ghost converts this to HTML:

<p>This is a sentence with a footnote.<sup id="fnref:1"><a href="#fn:1">1</a></sup></p> <div class="footnotes"> <ol> <li id="fn:1">This is the content that will appear in the popover bubble.</li> </ol> </div>

Step 3: Your browser loads the page and runs our code injection:

<!-- Littlefoot Core Library --> <script src="https://unpkg.com/littlefoot/dist/littlefoot.js"></script> <!-- This runs after the library loads --> <script> littlefoot(); // ← This activates all the popover magic! </script>

Step 4: Littlefoot.js automatically:

  1. Finds the <a href="#fn:1">1</a> link
  2. Reads the content from <li id="fn:1">
  3. Creates a button: <button class="littlefoot__button">1</button>
  4. Creates a popover: <aside class="littlefoot__popover">...content...</aside>
  5. Hides the original footnote at the bottom
  6. Adds click handlers to show/hide the popover

Step 5: Our custom CSS applies your brand colors to the button and popover.

Result: A fully functional popover that appears when clicked, styled in your brand colors!

⚠️ Why the Demo Looks Broken Locally

The Problem: When you open an HTML file directly (file:// URL), browsers block external scripts from CDNs for security reasons.

This means:

  • ❌ Littlefoot.js doesn't load from unpkg.com
  • ❌ Without Littlefoot.js, no popovers can be created
  • ❌ You see the original HTML links (blue, underlined)
  • ❌ Clicking them just scrolls to the bottom of the page
This ONLY happens with local files!

On your Ghost site (served via HTTPS), the CDN loads perfectly and everything works.
