# Demos & Examples

This folder contains demo and test files for visualizing Littlefoot footnotes.

## Files

### DEMO_infod_footnotes.html
Static HTML preview showing how the footnote buttons look with different styling options.

**What's inside:**
- Visual examples of dark and light color schemes
- Different symbol options (•••, †, ◆◆◆, ▸)
- Static button previews (not functional popups)
- Side-by-side comparisons

**How to use:**
1. Open `DEMO_infod_footnotes.html` in a web browser
2. View the visual styling examples
3. Note: These are static previews, not working footnotes

### HOW_IT_WORKS.html
Technical explanation and example of Littlefoot functionality.

**What's inside:**
- Basic Littlefoot implementation example
- Code structure explanation
- Working footnote example (may be blocked by browser security when opening locally)

**How to use:**
1. Open `HOW_IT_WORKS.html` in a web browser
2. Read the technical explanation
3. Note: CDN scripts may be blocked when opening from `file://` - upload to a web server for full functionality

## Important Notes

### Browser Security Limitations
When opening HTML files directly from your file system (`file://` protocol):
- External CDN scripts may be blocked
- Footnotes may not work as expected
- You may see errors in the browser console

To test properly:
1. Upload the file to a web server, or
2. View the live implementation on your Ghost site, or
3. Use a local development server

### These Are Demos Only
The demo files are for **visual reference only**. To actually install Littlefoot on your Ghost blog, use the files in the **root directory**:

- `UNIFIED Toggle Version - Install Once Use Everywhere.html` ⭐
- `SIMPLIFIED Styling littlefoot_Site Header Code_2025-12-27.html`
- `ALTERNATIVE SIMPLIFIED w CITATIONS LIST.html`

See the main **README.md** for installation instructions.
